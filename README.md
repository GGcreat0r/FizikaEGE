# Формулы по физике — тренажёр ЕГЭ (PWA)

Название формулы → выбери правильную из 3–5 похожих вариантов. 174 формулы по кодификатору ЕГЭ-2027 и сводке А. А. Суслова.

## Как выложить на GitHub Pages
1. Создай новый репозиторий на github.com (например, `formuly`), публичный.
2. «Add file → Upload files» → перетащи все файлы из этой папки (index.html, sw.js, manifest.json, icon-192.png, icon-512.png) → Commit.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/formuly/`.

## Как установить на телефон
- Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone (Safari): «Поделиться» → «На экран Домой».
После первого открытия работает офлайн. Прогресс хранится на устройстве.

## Управление с клавиатуры
1–5 или A–E — выбрать вариант, Enter/пробел — ответить / далее.
